# Original cue previews

These four WAV files are original synthesized tonal stingers generated by `scripts/create-audio-previews.mjs`. They are not spoken announcer recordings or imitations. The project creator may use them with the game.

`src/ui/announcer.js` provides local URL mapping, decode/preload, gesture-triggered AudioContext unlock, one-cue polyphony, abort and a safe synthesized fallback. Replace the four URL mappings with original or appropriately licensed spoken ROCK/PAPER/SCISSORS/SHOOT clips when available. Playback never affects match timing. Global sound and separate cue/SFX volumes apply.
